# Alan Fraley

Senior full-stack engineer in Northwest Arkansas. Python and Django on the backend, Vue and
React on the front, PostgreSQL/PostGIS underneath. Nine-plus years building production systems
end to end, mostly where something physical depends on the answer: geospatial data, drone and
satellite imagery, agriculture, and infrastructure inspection.

**Site:** [afraley.github.io](https://afraley.github.io/)

### Recent work

- **Decker**, bridge deck inspection (Alynix): Django/DRF and Vue 3 on a multi-tenant PostGIS
  model, with a thermal imaging pipeline that cut review time from weeks to days. Shipped to DOT
  pilots in multiple states. Private.
- **Agricultural data hub** for a national agriculture ministry, pro bono: Django, PostGIS,
  Vue 3, and MapLibre over Sentinel-1, Sentinel-2, and drought anomaly rasters. Private.

### Public repos
